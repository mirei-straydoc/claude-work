# claude-work

取引先ごとの定期実行（Claude スキル × スケジュールタスク）を管理するリポジトリ。

## 考え方

| 何を | どこで管理 |
|---|---|
| 仕組み（設定・スキルの元ファイル・テンプレート） | このリポジトリ |
| 中身（資料・成果物の PDF / Excel / 画像） | 共有ドライブ（各取引先の `設定.md` に場所を書く） |
| スキルの配布 | Claude のスキル設定（将来チームで使うならプラグイン化） |

- **スキル** は「作業の種類」ごとに 1 つ（例：週次作業レポート、請求書下書き）
- **スケジュールタスク** は「取引先 × スキル」ごとに 1 つ
- 取引先ごとの違い（文体・締め日・出力先など）は `取引先/<名前>/設定.md` に書き、スキルが実行時に読む

## フォルダー構成

```
claude-work/
├── README.md
├── 運用ルール.md
├── _共通/
│   ├── テンプレート/
│   │   └── 設定テンプレート.md   ← 新しい取引先を足すときにコピー
│   └── スキル/                    ← SKILL.md の控え（スキル名ごとにフォルダー）
└── 取引先/
    └── 具志堅樹/
        └── 設定.md
```

## 取引先を追加する手順

1. `_共通/テンプレート/設定テンプレート.md` を `取引先/<名前>/設定.md` にコピー
2. 中身を埋める（定期実行の表も）
3. 表の行ごとにスケジュールタスクを作る（Claude に「<名前> の設定.md どおりにタスクを作って」と頼めば OK）
